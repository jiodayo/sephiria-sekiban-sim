# セフィリア 石板配置シミュレーター

Sephiria(セフィリア)の「石板」を仮想バッグに配置して、効果(レベル増減・発動条件無視)の計算結果を
リアルタイムに確認できるツールです。あわせて、配置戦略(集中型/均等型/総火力型/安全型)に沿った
配置プランを自動生成します。

外部ライブラリなし・ビルド不要の素の HTML/CSS/JS のみで動作するので、そのまま GitHub Pages に置けます。

## ファイル構成

```
sekiban-sim/
├── index.html   … ページ本体
├── styles.css   … 見た目
├── app.js       … シミュレーション/戦略提案ロジック
├── data.js      … 石板54種のデータ(攻略Wikiより)
└── README.md
```

## ローカルで確認する

ブラウザは `file://` から JS モジュール的な読み込みを嫌うことがあるため、簡易サーバー経由での確認を推奨します。

```bash
cd sekiban-sim
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```

## GitHub Pages に公開する手順

1. GitHub で新しいリポジトリを作成する(例: `sekiban-sim`)。
2. このフォルダの中身をリポジトリ直下にコミットして push する。

   ```bash
   cd sekiban-sim
   git init
   git add .
   git commit -m "石板配置シミュレーターを追加"
   git branch -M main
   git remote add origin https://github.com/<あなたのユーザー名>/sekiban-sim.git
   git push -u origin main
   ```

3. GitHub のリポジトリページで **Settings → Pages** を開く。
4. "Build and deployment" の Source を **Deploy from a branch** にし、Branch を `main` / `/(root)` に設定して Save。
5. 数十秒〜数分待つと `https://<あなたのユーザー名>.github.io/sekiban-sim/` で公開されます。

すでにある GitHub Pages 用リポジトリ (`<ユーザー名>.github.io`) のサブフォルダとして置く場合は、
このフォルダごとそのリポジトリにコピーして push するだけで `https://<ユーザー名>.github.io/sekiban-sim/` のようなパスで見られます。

## 使い方

1. 左の「石板一覧」から石板をクリックして選択(回転可能な石板は選択中にRキーまたは「回転(R)」ボタンで向きを変更)。
2. 中央の「バッグ」の空きマスをクリックすると配置されます。配置済みのマスをクリックすると削除、
   Shiftを押しながらクリックすると回転します。
3. 各マスの数字は、そのマスに置いたアーティファクトが受けるレベル増減の合計値です(複数の石板の効果は加算されます)。
   青い枠は「発動条件を無視する」効果が乗っていることを示します。
4. 「占有マス指定」ボタンを押してからマスをクリックすると、既にアーティファクトが置かれている想定の
   マスとして石板を配置できないようにできます。
5. 右の「配置戦略プランを提案」で対象マスや使用枚数上限を設定し、「④ プランを生成」を押すと
   以下4種類のプランを自動計算して提示します。「このプランを盤面に適用」で中央の盤面に反映できます。
   - **① 集中型**: 指定した1マスに+効果を集中させる
   - **② 均等型**: バッグ全体になるべく均等に+を行き渡らせる
   - **③ 総火力型**: バッグ全体のレベル合計を最大化する
   - **④ 安全型**: マイナスマスの発生を避けつつプラスを稼ぐ

石板の所持数(パレット右側の数値入力)を0にすると、戦略提案の検索対象から除外されます
(まだ入手していない石板を除外して考えたいときに)。

## データについて・前提の注意

- 石板の効果パターンは Sephiria 攻略Wiki「石板」ページの表(灰=本体マス、緑=レベル+、赤=レベル-、
  青=発動条件無視)を画像として拡大確認し、本体マスからの相対座標として書き起こしたものです。
  Wikiの更新や読み取り誤りにより実際のゲーム内容と差異が生じる可能性があります。
- バッグのサイズは実際のゲーム仕様が不明なため、Wikiの効果範囲表と同じ「5行×6列」を既定値としつつ、
  画面上部の「行×列」入力でいつでも変更できるようにしています。
- 「回転」列が○の石板は、配置時に90度単位で向きを変えられる前提で計算しています。
- 配置戦略プランはランダム局所探索(焼きなまし法)による近似解です。理論上の最適解を保証するものではなく、
  「プランを生成」を押し直すたびに別の解が出ることがあります。
